# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Use the repository's **Security → Report a
vulnerability** button (GitHub private vulnerability reporting) and describe what you found and how to reproduce it.

Only the latest release is supported with fixes.

## Scope

Ward Tube has no server and keeps no account. Relevant reports include: a page or another app being able to reach the
app's download or file-access features, links that make the app read or write files it should not, and anything that
leaks the browsing history or downloads stored on the device.
